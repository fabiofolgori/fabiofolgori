# My own website, built the way I build yours

*Personal website · Nuxt lab*

My website had been frozen for fifteen years. I rebuilt it from scratch in Nuxt 4 as a lab: 3D scene, light and dark theme, animations, two languages, blog, AI assistant, automatic deploys, speed and security. What I can do, in a single project.

**Technologies:** Nuxt 4 · Tailwind CSS v4 · three.js · Nuxt Content · i18n · Claude API · Netlify
