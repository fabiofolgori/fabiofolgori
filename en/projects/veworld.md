# VeWorld, VeChain wallet

*Crypto wallet · Chrome extension*

VeWorld is the VeChain wallet for your browser, a Chrome extension to manage crypto assets and use dApps. In an international team I set up the app structure and built the frontend in React and TypeScript: wallet creation and import, assets, transaction confirmation.

**Technologies:** React · TypeScript · Redux · Chrome extension · VeChain · Blockchain
