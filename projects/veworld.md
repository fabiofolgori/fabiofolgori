# VeWorld, wallet VeChain

*Wallet crypto · Estensione Chrome*

VeWorld è il wallet di VeChain per il browser, un'estensione Chrome per gestire asset crypto e usare le dApp. In un team internazionale ho impostato la struttura dell'app e sviluppato il frontend in React e TypeScript: creazione e import dei wallet, asset, conferma delle transazioni.

**Tecnologie:** React · TypeScript · Redux · Estensione Chrome · VeChain · Blockchain
