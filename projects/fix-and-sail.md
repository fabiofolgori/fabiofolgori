# Fix and Sail

*Piattaforma per la nautica · Nuxt e Strapi*

Fix and Sail è una piattaforma in cui ricrei la tua barca in digitale, con modello e accessori, per seguirne manutenzioni e scadenze. È nata dall'idea di un cliente privato ed è ora in fase di lancio. Sviluppo l'applicazione in Nuxt su REST API Strapi, dal Figma al catalogo con riconoscimento AI dei pezzi da foto.

**Tecnologie:** Nuxt · Strapi · REST API · Figma · AI
